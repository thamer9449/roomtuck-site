Privacy Policy

This policy explains how the RoomBunny project handles information when its operator connects RoomBunny to YouTube through Google OAuth.

Google data we access

With the operator's consent, RoomBunny requests permission to upload videos to the authorized YouTube channel and read YouTube Analytics for that channel. RoomBunny does not request access to Gmail, contacts, Google Drive, passwords, or unrelated Google account data.

How the data is used

YouTube access is used only to publish original RoomBunny content and review channel performance such as views, watch time, retention-related analytics available through the authorized API, and subscriber performance. This information is used to operate and improve RoomBunny content.

Storage and security

OAuth credentials and tokens are stored in the private RoomBunny server environment and are not placed in public source code. Access is limited to the project operator and the automated services required to perform the authorized YouTube workflow.

Sharing and sale

RoomBunny does not sell Google user data. Google user data obtained through OAuth is not shared with advertisers or used for unrelated profiling.

Retention and revocation

Authorization information is retained only while the YouTube connection is needed. The operator can revoke RoomBunny's Google access at any time through the Google Account permissions page; after revocation, RoomBunny can no longer use that authorization.

Google API Services

RoomBunny's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.
